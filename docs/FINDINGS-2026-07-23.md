## B. CODE-REVIEW findings (two adversarial passes + self-review). NONE affects the current KQ4
patch (verified) -- all are latent generalization risks masked by KQ4's shapes. Ranked.

TIER 1 -- can ship a HARMFUL patch on another game, uncaught by verify():
1. `resource_remedies` single-valued branch (guards.py:385) deletes unconditionally. Generalizes the
   shovel's "one written value = dead"; a load-once/charge item's single write is ENABLING -> deleting
   it CREATES a softlock. The use-site compare polarity exists in source but `_IPROPS` discards it.
   FIX: delete a single-valued write only when its value is the side that FAILS the use-site read
   (needs the polarity captured in extraction; do NOT gate on `_clause_productive` -- the shovel break
   collides and would be kept).
2. `guard_register_write` wraps the INNERMOST `if` (patcher.py ~408, `es > encl[0]`). Docstring wants
   the WHOLE clock clause atomically; a nested nightfall leaks the divert/stash. KQ4 flat -> safe.
   FIX (1 line): outermost enclosing `if`, or the one whose condition names the trap register.

TIER 2 -- clear "fitted, not derived":
3. `free_running_traps` magic thresholds `reset<=3` / `trap>=10x` + baked `safe=0` (missability.py
   ~1330-1336). `safe=0` can't see a nonzero-baseline trap (and `0 not in dom` is dead code -- opmodel
   seeds every reg with {0}). g127 is rejected by the `<=3` threshold, not the "shape" idea the
   docstring sells. FIX: derive safe = more-pervasive value; relative dominance ratio, not constants.
4. arm-event wraps EVERY setScript incl. the RESUME site (trigger.py ~248). Unsound for an event that
   CONSUMES the item mid-sequence (hangs on re-entry). KQ4 whale consumes neither -> safe. FIX: gate
   only the START site.
5. `joint_frontier` over-placement + non-exhaustive if/elif (guards.py ~247-261). `flip_ins` is a
   GLOBAL union over all joint findings -> guard stamped on an unrelated gate's entries; both-deep ->
   walls, neither-deep -> silently DROPS (no verify net). KQ4 one-gate -> safe. FIX: restrict flip_ins
   to this item's source->need->gate path; handle both/neither explicitly.

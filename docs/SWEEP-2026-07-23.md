## Headline

**The decompiler is rock-solid; the analyzer runs on exactly one of the five, and halts on the
other four — all for the same reason.** The one that works (Space Quest 3) is a classic
puzzle-adventure with a death *global*. The four that don't (Camelot, TCB, QFG1, QFG2) each use
**imperative death — a bare procedure call at every hazard, with no "you died" global** — which our
death-signal *derivation* cannot see, so the run aborts before analyzing anything.

The sci-tools front-end decompiled **100%** of every game with **zero dialect fixes** (Camelot
226/226, TCB 244/244, QFG2 247/247, SQ3 123/123, QFG1 to completion). That half of the stack
generalizes cleanly. The *analysis* half is shaped tightly around the two reference titles.

## Per-game

### Space Quest 3 — WORKS end-to-end ✅
Start **rm900** (intro), victory **rm117** (verified: the ending, credits text + `endScript`).
83 rooms, 18 SCCs, 48 registers; analysed in 10s. **0 softlock items** — a plausible true-negative
(SQ3 is very linear; its failures are deaths/arcade sequences, not item-strandings). Two endgame
item-gates (rm2→21 Wire+Reactor; rm17→27 the ScumSoft finale set) are obtainable, so no stranding.
Derived **its own** death signal `(197, …)` — confirming derivation is per-game, not LSL2-borrowed.
The lone `REFUSED: Thermal_Detonator cannot be dropped anywhere` is a benign guard-synthesis note.

### Conquests of Camelot — HALTS (death) + a dropped world ⛔
226/226 decompiled, then **`SystemExit: could not derive a death signal`**. Death is an
unconditional call to free procedure **`proc128_0`** (Restore/Restart/Quit dialog) at **53 sites
across 40 scripts** — no death global exists. Forced past it, a **second gap** surfaces: `rm1` is the
**overland map**, and travel is `(newRoom: [local-array][clicked-control-region])` — destination read
from a local array indexed by the PIC control map. The extractor resolves only
`newRoom:<literal>`/`<global>`, so it drops every map edge, severs the hub, and collapses both
anchors to rm1 (spurious "0 softlocks"). Also unmodeled: a **coin economy** (purse, bazaar
haggling) and **arcade combat with a stamina/health resource** (`finalBattle` `staminaUpdate`).

### The Colonel's Bequest — HALTS (death) + structurally out of model ⛔
244/244 decompiled, then the **same death-signal halt**: death is `proc0_19` (Main.sc:661), ~30 call
sites, no global. Forced past it, it exposes that the *whole* model doesn't fit a time-advancing
mystery:
- **"Victory room" is unsound without a death global** — `discover_goal` returns *every* terminal
  room `[64, 215, 786]`. rm786 is the real ending: the **Sleuth-O-Meter**, a graded **score 0–4**,
  not a win-place.
- Progression is a **real-time clock** (`global186` hour) + an **8-act counter** (`global165`)
  driving 40 per-character schedule machines — a whole time axis the model has no dimension for.
- Forced, the guard synthesizer **invents 2 false-positive strandings** (carrot = a load-if-carried
  cel misread as a gate; pouch = a DNF artifact). True answer: 0.

### Quest for Glory 2 — HALTS (death) + memory wall + endgame dropped + calendar invisible ⛔
247/247 decompiled, then the **death-signal halt** (death = `proc1_24`, "Ouch!"→dialog, no global).
**Even forced past it the model never builds** — `OpEmitter` construction over 247 scripts climbs
past **2.8 GB and thrashes** (MemoryError under a 2 GB cap in 38 s). Two more structural gaps:
- **Room-inheritance blind spot**: QFG2 inserts intermediate base classes (`Stage of Rm`,
  `RasPlaza`, `AlleyRoom`); room detection checks only **one level** (`o.super == Rm`), so **11 rooms
  drop — including the Raseir plaza/palace endgame** where the game is won.
- **The 30-day calendar is the game's spine and invisible to us**: `global110` advances on the
  **real-time clock** (`proc2_17`), a hard **day-30 forced ending → rm790**, and dozens of day-gated
  events (day-8 duel, day-17 kidnapping). This is exactly KQ4's nightfall "free-running trap"
  shape — but pervasive. (`derive_debug` *does* work here — finds `global101`.)

### Quest for Glory 1 (EGA) — same class as QFG2; killed to spare the machine ⚠️

## What we're missing (ranked by leverage)

1. **Imperative death — the #1 blocker.** Four of four non-reference titles kill the player with a
   *procedure call* (or a stat threshold), not by setting a sentinel global. `vocab.derive_death`
   only matches "`if <global-test> → restart:/restore:`" (LSL2 `gCurrentStatus==1001`, KQ4
   `global127`), so it returns nothing and the run **hard-halts** (`missability.py:1433`). This one
   gap, not any exotic mechanic, is why the tool can't even *start* on Camelot/TCB/QFG1/QFG2.
   → **Teach `derive_death` a third idiom**: a free procedure that offers `restart:`/`restore:` at
   its own call sites *is* the death routine; its call sites are death edges. High leverage.
   → **DONE 2026-07-23.** `vocab.derive_death_proc` detects the PUBLIC death procedure (offers
   restart/restore; a `localproc` is menu/helper code and excluded); `vocab.lower_death_procs`
   rewrites each call to it into a synthetic death-flag write (one global past the game's highest),
   so the whole `is_death` machinery applies unchanged. Wired into `missability` only when the
   global-flag shape is absent, so **LSL2/KQ4 stay byte-identical** (verified vs baseline + golden +
   ground-truth). Unblocks Camelot/TCB/QFG/KQ5 past the halt; populating death-rooms also tightens
   anchor discovery (TCB victory set `[64,215,786]`→`[64,786]`). The next walls surface underneath:
   the map-travel / room-inheritance extractor gaps (#4) and the OpEmitter memory wall (#3).
2. **Halt-or-fabricate on out-of-class games.** When death can't be derived the tool either
   `SystemExit`s (native) or, forced, **invents false-positive strandings** (TCB's carrot/pouch) and
   **collapses anchors** (Camelot rm1, TCB terminal-room victory set). → Detect "no death signal / no
   single victory / score-graded ending" and **report an unsupported-class verdict** instead of
   guessing.
3. **Model-construction memory wall.** QFG2 (247) and QFG1 (282 scripts) exhaust >2.8 GB building
   the state-machine lift before `analyze()` is even reached. → the COI / model-reduction lever
   already on the roadmap; the current lift doesn't scale to full RPG script counts.
4. **Extractor navigation gaps** (each drops real edges): `newRoom:[array]` map-node travel
   (Camelot), one-level-deep room-inheritance detection dropping intermediate-class rooms incl.
   QFG2's endgame, and direction-property `newRoom:(global2 north:)` desert navigation (QFG2).
5. **Unmodeled stores that are real softlock vectors**: a **money economy** (Camelot purse, QFG
   dinars/silver/copper), **combat stamina/health**, **skill arrays** (QFG `global571[]`/`global139[]`),
   and the **real-time day calendar** (QFG2 `global110`) — which is the free-running-trap shape we
   already model for KQ4 nightfall and *would* catch, if the model built and the run got that far.

## What's solid
- **The decompiler front-end generalizes** — 100% on four unseen SCI0 titles, no dialect work.
- **The tool is sound on its target class** — SQ3, a real puzzle adventure with a death global, runs
  end-to-end with correct anchors and a defensible 0-softlock result. The failures are honest halts
  on games outside that class, not silent wrong answers (except the two forced-run false positives,
  which is exactly why #2 above matters).
